# Tooka documentation

Tooka sorts files with rules you write in YAML: *which files* (by name,
extension, size, dates, EXIF data, ...) and *what to do* with them (move,
copy, rename, delete, run a command).

| Page | What it covers |
|---|---|
| [Installation](installation.md) | Packages, `cargo install`, building from source |
| [Getting started](getting-started.md) | Your first rule and your first sort, step by step |
| [Rules](rules.md) | Complete reference of conditions, actions and `on_conflict` |
| [Sorting](sorting.md) | What a sort does, its safety guarantees, reports, `tooka recover` |
| [Monitoring](monitoring.md) | Sorting folders automatically in the background |
| [Configuration](configuration.md) | Where Tooka keeps its files, environment variables, logs |
| [Commands](commands.md) | Every command and option |
